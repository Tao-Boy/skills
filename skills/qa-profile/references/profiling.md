# 撰写用户画像

画像由两部分组成，由 `profile` 命令一起展示：

| 部分 | 来源 | 内容 |
|---|---|---|
| 统计 | 脚本根据记录自动计算，不需要手写 | 主题掌握度、能力维度均分、判定分布、问题类型、误区汇总、自信校准、近期趋势、待处理记录 |
| 判断 | Agent 通过 `profile-update` 写入 | summary、level、traits、preferences、goals、recommendations、误区状态 |

## 统计口径（便于解读）

- **掌握度**：某主题下已评分记录的 overall/100 的加权平均。最新的一条权重为 1，往前每隔一条乘以 0.85；
  难度越高，权重越大（难度/3）。统计会在主题的每一层分别汇总，例如「物理」「物理/电磁学」「物理/电磁学/高斯定理」。
- **水平标签**：≥0.8 为精通，≥0.6 为熟练，≥0.4 为基础，其余为薄弱。记录少于 2 条时标为「数据不足」。
- **confidence** = n/(n+3)：样本越多，越可信。
- **趋势**：比较最近 3 条与再往前 3 条的平均分，差值超过 ±0.1 判为上升或下降。
- **自信校准**：自评把握度减去实际得分，取平均。大于 0.15 为偏自信，小于 −0.15 为偏保守；需要至少 3 条样本。

## 判断部分的写法

- **summary**：2–4 句，按「整体水平 → 突出的强项 → 主要短板或误区 → 近期变化」的顺序写，每句都应该能在记录里找到依据。
- **level**：用自然语言描述整体水平，例如「高中物理竞赛入门」「本科中等」，并注明是相对于哪个参照。
- **traits**：可观察到的作答习惯和思维方式，例如「先给结论、推导简略」「善于类比」「遇到计算容易跳步」。
  每条至少要有 **2 条记录**作为证据，`confidence` 不超过 0.5 + 0.1 × 证据条数。
- **preferences / goals**：主要来自 preference、background 类问题，或者用户的明确表述。
- **recommendations**：具体、可执行，并且与短板对应，例如「练 3 道需要先判断对称性的题」，而不是「多练习」。
- **误区状态**：
  - 用户后来在同一个概念上答对，并且能说明理由：改为 `resolved`，并附上证据；
  - 复查时又犯同样的错：保持 `active`；
  - 当初是误判：改为 `dismissed`，同时用 `revise` 修订原来的评估。

## 禁止推断的内容

画像只描述与问答直接相关的能力、知识、学习方式和用户明确表达的偏好。**不要**推断或记录：

- 健康状况、心理状态、智商这类标签；
- 政治立场、宗教信仰、性取向、民族、收入等敏感属性；
- 与问题无关的个人隐私（用户主动提供，并且与学习目标相关的背景除外，记入 `subject.about`）；
- 对人格的结论（例如「懒惰」「不认真」），应改写为可观察的行为（例如「多题未写推导过程」）。

## 用画像指导下一轮提问

1. 优先考察：处于 active 状态的误区所对应的概念；掌握度为「薄弱」或「基础」的主题；很久没有考察过的主题（看 `last_seen`）。
2. 难度要自适应：最近连续答对就把难度加 1，连续答错就减 1，尽量让正确率保持在 60%–80% 之间。
3. 复查误区时，换一种问法或情境来考察同一个概念，并用 `parent` 指向最初暴露这个误区的记录。
4. 如果画像显示用户偏自信，可以多问「你有几成把握？」，以便继续积累校准数据。
