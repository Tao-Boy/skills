# 评分标准

## 维度与锚点（默认 rubric，0–4 分）

| 维度 | 权重 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|---|
| correctness 正确性 | 0.4 | 错误或答非所问 | 主要结论错误，仅零星正确 | 部分正确，有明显错误 | 基本正确，有小瑕疵 | 完全正确 |
| completeness 完整性 | 0.2 | 没有覆盖期望要点 | 覆盖约 1/4 | 覆盖约一半 | 覆盖大部分 | 覆盖全部要点 |
| reasoning 推理与论证 | 0.2 | 没有推理，或推理错误 | 推理有关键漏洞 | 有推理，但跳步或不严密 | 推理基本严密 | 清晰严密，能说明为什么 |
| clarity 表达清晰 | 0.1 | 难以理解 | 勉强能懂 | 能懂，但组织松散 | 清楚 | 条理清楚且简洁 |
| precision 术语与符号规范 | 0.1 | 术语或符号混乱 | 多处不规范 | 偶有不规范 | 基本规范 | 规范准确 |

- 只给适用的维度打分。例如事实题可以不打 reasoning 分，未打分的维度不参与加权。
- `overall` = Σ(权重 × 分数/4) / Σ(所用维度的权重) × 100，脚本会自动计算。只有在特殊情况下才需要手动填写。
- 打分只看**这一次作答**，不受用户历史表现的影响。
- 需要不同标准时（例如面试中考察「沟通」「系统设计」），用 `rubric set` 替换评分标准。替换时要保留已经用过的维度，rubric 的版本号会自动加一。

## verdict

| verdict | 判定条件 |
|---|---|
| `correct` | 核心结论正确，没有实质性错误 |
| `mostly_correct` | 核心正确，但有遗漏或表述不准 |
| `partially_correct` | 部分正确，存在实质性错误或重要遗漏 |
| `incorrect` | 核心结论错误 |
| `no_answer` | 不会、放弃作答或答非所问（overall 记为 0） |
| `not_applicable` | 观点、偏好、背景类问题，没有对错之分（不计入掌握度） |

## issue 类型

| type | 含义 | 判断要点 |
|---|---|---|
| `misconception` | 错误的心智模型 | 回答中能看出系统性的错误理解，**必须填写 `concept`**，并且每次使用同一个名称 |
| `knowledge_gap` | 知识缺失 | 不知道某个概念或结论，但没有错误理解 |
| `reasoning_error` | 推理错误 | 前提正确，推导过程出错 |
| `calculation_slip` | 计算或笔误 | 思路正确，只是偶然出错；**不要**记为误区 |
| `imprecision` | 表述不准 | 意思大致对，但术语或条件不严谨 |
| `incomplete` | 不完整 | 漏掉了期望要点 |
| `off_topic` | 偏题 | |
| `unclear_expression` | 表达不清 | 无法判断用户真正的意思 |
| `other` | 其他 | 在 detail 中说明 |

## 评估流程

1. 逐条对照 `expected_points`：哪些覆盖了，哪些遗漏了，哪些答错了。
2. 找出回答中支持每个判断的**原文片段**，放进 `evidence`（逐字引用，可以只截取一部分）。
3. 先定 verdict，再按锚点给各维度打分；两者要一致（例如 verdict 是 correct，correctness 就不应低于 3）。
4. 写 `strengths`（具体的优点）和 `issues`（类型 + 概念 + 具体说明）。
5. `confidence`（0–1）表示你对这次评估本身有多大把握。用户表达含糊、或者题目本身有争议时，应调低。
6. `feedback`：指出对在哪里、错在哪里、为什么错，再给一个下一步建议。不要直接给出完整答案，除非用户要求，或者场景是辅导。

## 示例

题目：「高斯定理在什么条件下能方便地求出电场？」期望要点：①定理对任意闭合曲面都成立；②求场需要高度对称；③E 能提到积分外。

用户回答：「只要曲面是球面就能用它求电场。」

```json
{"verdict": "incorrect",
 "scores": {"correctness": 1, "completeness": 1, "reasoning": 0, "clarity": 3, "precision": 2},
 "issues": [{"type": "misconception", "concept": "高斯定理求场条件",
             "detail": "把高斯面的形状当成条件，忽略了电荷分布的对称性"}],
 "evidence": ["只要曲面是球面就能用它求电场"], "confidence": 0.9,
 "feedback": "高斯面可以任意取，关键在于电荷分布是否足够对称，使 E 在面上大小相同、方向与面垂直。想想：一个偏心放置的点电荷，用球面能求出场吗？"}
```
